# Brand assets

## berkhamsted-logo.png  (you must supply this)

Upload the official Berkhamsted School logo to this directory as exactly:

    berkhamsted-reading-signature/public/assets/berkhamsted-logo.png

Guidance:

* **Format:** PNG. Email clients render SVG unreliably, so the signature needs a raster logo.
* **Width:** around 600px works well. It is displayed at 180px, so this keeps it crisp on
  high-DPI screens without bloating the email.
* **Background:** either transparent or the brand navy (#0A2142).

No logo is generated, downloaded or substituted by this project. If the file is absent the
application renders a clearly-marked placeholder instead of crashing, both in the dashboard
and in the public signature.
